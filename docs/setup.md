# Local Setup

## Prerequisites

- Node.js
- Package manager
- Database
- Cloud storage credentials
- AI API key

## Setup goals

- Run frontend locally
- Run backend locally
- Connect to the database
- Upload files safely in development
- Test core patient flows

## Environment files

Use separate env files for:

- local
- staging
- production

## Basic setup flow

1. Install dependencies
2. Configure environment variables
3. Start database
4. Run migrations
5. Start backend
6. Start frontend
7. Verify auth and upload flow

## Notes

- Never commit secrets
- Never hardcode API keys
- Keep local setup repeatable
