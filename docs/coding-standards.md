# Coding Standards

## General

- Use TypeScript
- Keep code readable
- Avoid unnecessary complexity
- Prefer small functions
- Prefer reusable components

## Frontend

- Keep UI components focused
- Avoid large component files
- Keep styles consistent
- Use clear prop names
- Use shared UI components where possible

## Backend

- Keep controllers thin
- Put business logic in services
- Validate all inputs
- Return predictable error formats
- Keep database access isolated

## Naming

- Use clear and consistent names
- Avoid abbreviations unless obvious
- Use feature-based naming for files and folders

## AI rules

- AI output must be helpful and cautious
- Do not present AI as a doctor
- Do not overclaim certainty
- Keep AI text simple and user-friendly

## Quality rules

- No dead code
- No duplicated logic
- No hidden side effects
- No random architectural experiments
