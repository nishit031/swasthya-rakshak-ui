# Swasthya Rakshak

Swasthya Rakshak is a patient-first digital health companion that helps users securely store, organize, understand, and manage their health journey in one place.

## MVP focus

The MVP is only for patients.

### Included

- Account creation and login
- Health vault for medical records
- Smart health timeline
- Family member profiles
- Reminders
- Basic AI-assisted summaries
- Secure record sharing

### Not included

- Clinic SaaS
- Hospital SaaS
- Insurance
- Billing
- Telemedicine
- Doctor dashboards

## Product philosophy

- Start with the patient
- Keep healthcare simple
- Build trust through usefulness
- Use AI as an assistant, not a replacement

## Development approach

- Clean architecture
- Modular code
- TypeScript-first
- Production-ready from the start
